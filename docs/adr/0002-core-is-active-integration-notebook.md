# 核心是 AI 主动整合的"学习项目笔记本"（沉淀引擎），不是被动笔记应用

工具的核心是一条学习循环：打开看到最近在坚持的笔记 → 出去学 → 把材料喂进来 → LLM 把材料整合进对应笔记（去重/总结/体系化）。单位是"笔记"——灵感是笔记的幼体，凡"需要被记录、不能丢"的都是笔记。

LLM 的关键能力是【整合】而非 CRUD：用户只管倾倒原始材料，LLM 自动结构化（标题/标签/摘要）并整合进笔记，消灭"建卡要手填一堆参数"的捕获摩擦——这正命中用户最初的"开始的门槛高"之痛。

这修订了 ADR-0001：单位从"原子灵感 + 类型化关系图"改为"笔记 + 整合"（用户确认在"往笔记加东西"的模型里，想法间类型化关系不再需要）；"不是笔记应用"修订为"不是被动笔记应用"——本工具是 AI 主动整合的笔记，区别于 Obsidian。读档、消灭重复建档仍是不变的核心。

## Status
accepted（supersedes ADR-0001）
