# 核心是"存档 + 自动读档"，不是笔记应用或执行追踪

> **Status: superseded by [ADR-0002](./0002-core-is-active-integration-notebook.md)。** 单位从"灵感 spark + 关系图"修订为"笔记 + 整合"；"非笔记应用"修订为"非被动笔记应用"。读档与消灭重复建档作为核心不变。本文保留作历史。

工具的核心是捕获（存档）与捕获瞬间的自动检索（读档）耦合，专门消灭"同一个想法被反复建成新档案、永不相识整合"的重复建档。

刻意没有作为核心的：
- **单独的整理/归类动作** —— Obsidian 已证明手动归类维护不住，用户自述"规划很差"。
- **执行/项目推进** —— 那是后续阶段；一上来就做会把工具变成项目管理器，偏离"接住灵感"的初衷。

读档由 AI 在存档时自动触发，而非要求用户自己去搜索回忆：用户无法回忆每个想法是否提过，手动检索等于没有。
